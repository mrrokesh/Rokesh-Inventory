# Reports

Go to **Reports** in the left menu. Each report answers one question. Pick a period at the top (and a warehouse, where it applies), then **Export Excel**, or **Print / PDF**.

## Which report should I open?

| I want to know… | Open |
|---|---|
| How much stock I have of each item | **Inventory Summary** |
| What my stock is worth | **Inventory Valuation Summary (FIFO)** |
| What came in and went out this month | **Stock Summary** |
| What I need to reorder | **Low Stock Items** |
| What has run out | **Out of Stock Items** |
| Every stock movement, line by line | **Stock Movement** |
| Stock in a particular warehouse | **Warehouse Stock** |
| Which stock has been sitting too long | **Inventory Aging** |
| Which items matter most to my sales | **ABC Analysis** (A = top 70% of sales value) |
| What sells best and my profit per item | **Sales by Item** |
| Who my biggest customers are | **Sales by Customer** |
| How each salesperson is doing | **Sales by Salesperson** |
| Which orders are still not shipped/invoiced | **Order Fulfillment** |
| Who owes me money and how late | **Customer Balances** |
| Payments I received | **Payments Received** |
| Whom I buy from the most | **Purchases by Vendor** |
| What I bought, item by item | **Purchases by Item** |
| Which purchase orders are still open | **Purchase Order Details** |
| Whom I owe money and how late | **Vendor Balances** |
| Payments I made | **Payments Made** |
| Tax collected and paid | **Tax Summary** |
| Whether I made a profit | **Profit and Loss Summary** |

## Understanding the profit report

- **Sales** – the value of invoices you issued (before tax).
- **Cost of goods sold** – what the goods you sold cost you (FIFO).
- **Gross profit** = sales − cost of goods sold.
- **Net profit** also subtracts stock losses from adjustments, non-stock bills (rent, services…) and shipping costs.

> This is an operational summary to help you run the business. Your accountant's books remain the official record for tax filing.
