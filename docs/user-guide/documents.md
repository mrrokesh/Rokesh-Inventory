# Documents, attachments and printing

## Attach files to a record

Every item, customer, vendor, order, invoice, bill and shipment has an **Attachments** box on its page.

1. Open the record.
2. In **Attachments**, press **Upload files**.
3. Pick one or more files – PDF, photos, Excel, Word – up to 10 MB each.

Good things to attach: the vendor's bill PDF, e-way bill, signed delivery challan, photos of damaged goods, contracts.

## The Documents library

**Documents** in the left menu shows every file in one place.

- **Search** by file name or category.
- Filter by **Attached to** to see, for example, all files attached to bills.
- Upload files that don't belong to a record yet (contracts, licences). Type a **Category** first to keep things organised.
- Click a category to change it, or the file name to open it.

## Print or save as PDF

Every sales order, invoice, purchase order, bill, credit note, package (packing slip), shipment and payment receipt has a **Print / PDF** button.

1. Press **Print / PDF**.
2. In the print window, choose your printer – or choose **Save as PDF** as the destination to create a PDF file.

Only the document is printed; the menus and buttons are hidden automatically. Your logo and address come from **Settings → Organization profile**.
